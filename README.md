# FrameStudio Android

FrameStudio adalah editor video Android tahap awal, ditujukan untuk perangkat Android termasuk Samsung Galaxy A52s.

## Fitur pada MVP 0.1
- Memilih video dari penyimpanan perangkat.
- Pratinjau video.
- Memotong video berdasarkan waktu mulai dan akhir (detik).
- Ekspor hasil sebagai MP4 ke Galeri pada folder Movies/FrameStudio.

## Build APK
Build otomatis berjalan melalui GitHub Actions setiap ada push ke branch `main`, atau dapat dijalankan manual melalui tab Actions.

APK debug tersedia sebagai artifact bernama `FrameStudio-debug` setelah workflow selesai dengan status sukses.

## Catatan
Ini adalah MVP awal, belum setara CapCut. Fitur timeline multi-klip, foto, audio, teks, transisi, filter, keyframe, dan kontrol kecepatan akan dikembangkan bertahap. APK belum dinyatakan siap dipasang sebelum proses build berhasil.
